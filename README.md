# 🧠 Problem-Solving Frameworks

I don't start with the dashboard.

I start with the **business question**.

### 🔎 Root Cause Analysis — RCA
Identify the problem → segment the data → isolate drivers → validate hypotheses → recommend action.

### 🧪 A/B Testing
Define hypothesis → establish control/treatment → measure effect → test statistical significance → translate results into business impact.

### 👥 Cohort Analysis
Group customers/users by a meaningful starting event → track behavior over time → identify retention, conversion and value patterns.

### 📊 Data Analysis
EDA → data quality → distributions → relationships → segmentation → drivers → insights.

### 🤖 Machine Learning
Feature engineering → baseline → model selection → validation → interpretation → business application.

### 📐 Statistics
Hypothesis testing → confidence intervals → effect size → regression → correlation → statistical significance.
